NHS Specialties & Treatment Functions

View source on GitHub

An index of NHS main specialties and treatment functions from the NHS Data Dictionary, built into a factsheet per specialty, with a graph layer showing how specialties connect through their clinical roles. The first layer is doctors and medical staff: career grades, the shared training pathways that feed several specialties, and special-interest roles that cut across them.
